# Ubuntu 24.04 / E610 实机安装验证

日期：2026-10-21。使用已发布的 `v6.4.5-ubuntu24.04-6.8.0-31-r1` 离线包，
通过带外控制台安装并重启，保留 `6.8.0-31-generic` 内核。

硬件 E610 PCI ID 为 `8086:57b0`。重启后两个端口均绑定 `ixgbe 6.4.5`，
磁盘模块路径解析至本包的 `updates/e610/ixgbe.ko`。
操作开始时 Secure Boot 已关闭，本次没有修改该设置。

一个端口接线并以 1000Mb/s 全双工连接，按用户要求配置 DHCP；另一个端口已识别、
配置 DHCP，检查时没有物理链路。网关 ping 3/3；外网首次 ping 2/3，复测 5/5；
Ubuntu 软件源域名解析成功，HTTPS 请求返回 HTTP 200；管理端 TCP 22 连通。
未单独验证 SSH 用户认证。

已有 RX 错误计数为 9（CRC 8、长度错误 1），后续检查未增长；TX 错误和发送超时为 0。
未做 10Gbps、高速吞吐、长时间稳定性、PTP 或 SR-IOV 验收。

安装文件和回退备份保留在服务器；原有网络配置保留并备份。
安装完成后已卸载驱动光盘并断开 BMC 虚拟介质。
